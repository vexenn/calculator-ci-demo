# CI/CD Calculator Project

An enhanced full-stack calculator application featuring advanced mathematical logic, a clean web-based user interface, full test coverage via Jest, and zero-configuration code quality enforcement using ESLint flat configs.

## 🚀 Features
- Core operations: Addition, Subtraction, Multiplication, and Division.
- Bonus operations: Square and Cube calculations.
- Responsive, center-aligned frontend user interface.
- Complete automation pipeline for continuous integration.

## 🛠️ Local Installation & Setup

To get the project running locally on your machine, ensure you have Node.js installed, then execute the following commands in your terminal:

```bash
# Install project dependencies
npm install

# Run the test suite
npm test

# Run code style linting checks
npm run lint
